# damtol

Web app analisis damage tolerance dan fatigue (pesawat transport, militer, rotorcraft), versi 2.54.3.

**Buka:** https://lamina27.github.io/damtol/

Di iPhone: buka alamat di atas dengan Safari, lalu Bagikan, lalu "Tambahkan ke Layar Utama". Setelah dibuka sekali
dengan internet, aplikasi tetap jalan tanpa internet. Di Android: Chrome, lalu menu, lalu "Instal aplikasi".

Semua hitungan berjalan di browser; tidak ada data yang dikirim ke server. Case yang disimpan otomatis hanya ada di
browser itu; pakai "Simpan case" dan "Buka case" untuk memindahkannya.

**Status:** alat bantu studi dan pembanding. Belum dikualifikasi (shadow run dan review independen belum selesai);
jangan dipakai langsung untuk sertifikasi. Status tiap rumus (V, P, U) dan sumbernya ada di bagian 0 web app.

File di repo ini dibuat oleh `tools/make_pwa.py` dari `web/damtol.html`; jangan diedit langsung.
